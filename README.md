# GlassHarbor

Optimizes high-performance real-time data processing on scalable cloud platforms through auto-scaling and load-balancing engine architecture.

GlassHarbor is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/GlassHarbor.git`
2. `cd GlassHarbor`
3. Install in editable mode: `pip install -e .`

## Configuration

GlassHarbor is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
